# RideLink Microservices Backend

RideLink is a backend microservices system built with Spring Boot, Java 17, and MongoDB.

## Microservices Architecture
- **account-service**: Manages user profiles and authentication.
- **driver-service**: Manages driver onboarding and status tracking.
- **ride-service**: Handles ride bookings and route tracking.
- **fare-payment-service**: Manages fare calculation and transaction processing.

## Tech Stack
- **Framework**: Spring Boot
- **Language**: Java 17
- **Database**: MongoDB
- **CI/CD**: GitHub Actions
